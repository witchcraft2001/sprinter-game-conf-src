# Game graphics: исправленная постановка

Game-графика Sprinter/TITD использует **байтовые индексы цвета (8bpp)**.
Удвоение каждого пикселя в MAME не означает два 4-битных индекса в байте.
MODE0[1:0]:MODE1 задают X, MODE2 — Y; MODE3 содержит X/Y scroll по 4 бита.
MODE0[2] загружает scroll, MODE0[7:6] выбирают палитру, старшие биты также
кодируют border/blank/interrupt. Адреса графики могут быть невыровненными.

Нельзя переносить `lookback_scroll`, повторное применение одного control в MAME,
программные адресные формулы или предполагаемые сбросы на каждой строке/кадре
непосредственно в FPGA. Нужны реальные SRAM банки, фазы захвата и задержка palette.
Физический растр не должен изменяться от scroll.

Реализация-кандидат, точная рабочая семантика, ограничения проверки и инструкции:
[docs/GAME_K50.md](docs/GAME_K50.md). Исходная game_patch.md в данном checkout
отсутствовала; этот документ фиксирует исправленные предпосылки вместо прежних
предложений из плана.
