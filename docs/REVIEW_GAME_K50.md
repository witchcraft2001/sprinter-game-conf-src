# Кодревью GAME_K50 — 10 октября 2026

План выполнен в части исходников, инструментов и локальных проверок. Полностью
завершённым результат не является: нет новой Windows-сборки SOF/TTF/ACX, fitting
report с K50, проверки CLK42/SRAM/DAC и испытаний платы/TITD. Синтетический файл
из packer не выдаётся за FPGA-прошивку.

## Замечания и исправления

| Приоритет | Найдено | Исправление / статус |
|---|---|---|
| Высокий | BIOS GetMemBlkPages пишет список **и FF terminator**, четырёхбайтный буфер портил следующий scroll | Буфер 256 байт; проверка B; Z80-тест списка и начального scroll |
| Высокий | Диагностика принимала короткий DSS.Read с carry=0 и не проверяла ошибку AcexSetUpNow | Сравнение возвращённого DE с запросом, carry BIOS; отказ проверен в Z80 |
| Высокий | Диагностика передавала BIOS четыре страницы при любом размере файла | Выделяются ровно ceil(size/16384) страниц; хвост FF; проверены размеры 7…65536 |
| Средний | Диагностика требовала первый zero-run строго 01, хотя он может продолжать нули за заголовком | Принимается любой ненулевой счётчик, файл короче 7 байт отвергается; count 2/255 и усечение проверены |
| Средний | OR старших битов адреса X превращал диагностический blank FC в interrupt FD | Адресные биты добавляются только обычной графике; проверены все карты |
| Высокий | Удаление всех LC/EAB в стандартном staging изменяло контрольную конфигурацию и write delays | Размещения сохранены, pins сохранены; аудит требует Windows fitting review |
| Средний | PowerShell 5.1 был дополнительной зависимостью, упаковочные проверки здесь не исполнялись | Штатный cmd + WSH/JScript; один core исполняется cscript/Node; 20 тестов прошли |
| Высокий | Самописная модель не проверяла выражения нового TDF | Ограниченный интерпретатор фактического read pipeline; обе страницы/полный растр, scroll 0…15, банки/палитры/спецрежимы; четыре мутации выявляются |
| Высокий | Формат ACX выводился из названия, без выполнения загрузчика | Выполнены TITDREV startup и BIOS header check/bit sender; zero-packer поток с offset 0, K50 signature, страницы/размеры проверены |
| Средний, внешний код | TITDREV использует JP NZ после ADD HL,BC, сохраняющего Z; не проверяет фактический DE DSS.Read | Подготовлен tools/titdrev_acx.patch. Собран и проверен в временной копии; внешний репозиторий не изменён |

| Пункт плана | Статус и предел подтверждения |

| Четыре байта, MODE3=VDM0, действительные фазы SRAM | Реализовано; source-linked цифровая проверка; электрический setup/hold ещё не измерен |
| Отдельные физические счётчики и выборка, scroll/невидимые клетки/кадр/две страницы | Реализовано; проверены модель и выражения TDF; исходные counters сохранены |
| Однократный control, отсутствие сбросов на строке/кадре | Реализовано; загрузка через один CLK42 после захвата, следующая выборка; power-up предстоит подтвердить в netlist |
| Byte-addressed graphics, четыре банка/палитры, border/blank/IRQ | Реализовано; цифровой read pipeline проверен; общий INTT использует прежний производный CT[5], весь тракт IRQ/DAC нуждается в аппаратной проверке |
| Окна CPU/акселератора, формат ресурсов | Интерфейс/write-тракт сохранены и сравнены с K50; новых CPU-портов нет |
| Чистые Windows standard/game сборки, явный K50, отказ от старых результатов | Реализовано; core/staging проверены, cmd/WSH/MAX+plus II пока не запускались |
| SOF/TTF/raw/packed/ACX/report/log, roundtrip, <=64 КиБ | Pipeline реализован и проверен на синтетических данных; настоящих новых FPGA-артефактов нет |
| Выходной файл для загрузчика TITD | Проверен формат внешнего K50.ACX **для TITDREV**. Оригинальный TITD/TITD0 требует другой GAME_00.ACX и не поддерживает этот путь |
| DSS аппаратная диагностика | Исходники/ассеты/сборка и 18 Z80-сценариев готовы; плата не проверена |
| Стандартный K50, TITD целиком, fitting и timing | Ожидают Windows и плату пользователя; приёмка не завершена |
| MAME и оригинальная K30 | Используются только как источники; netlist и недокументированная эквивалентность ими не подтверждены |
